# Задания

## Задание 1.1: клиенты (customers) с именем 'David'. Сортировка: Фамилия.

Модернизация запроса:
1. фамилия выводится первой по нормам русского языка,
2. выведены только самые важные данные для выгрузки.

Скрипт для выволнения запроса:

```sql
select last_name, first_name, gender, email, phone, latitude, longitude 
from customers
where first_name = 'David' 
order by last_name asc
```

## Задание 1.2: письма (emails), отправленные весной (март-май) 2015 года.

Модернизация запроса:  
1. сокращение периода,
2. введение допольнительных условий для оптимизации выгрузки.

Скрипт для выволнения запроса:

```sql
select email_subject, bounced, sent_date
from emails
where sent_date between '2015-04-01' and '2015-05-01' and opened_date is not null and clicked = 't'
order by sent_date asc
```

## Задание 1.3: таблица autos (тип 'automobile'). Цену умножить на 1.05. Удалить год < 2000.

Модернизация запроса: 
1. из-за ошибки в задании, изменены названия таблицы и атрибутов,
2. изменено условие (год не 2000, а 2013), тк данные в таблице все моложе 2010 года

Скрипт для выволнения запроса:

```sql
create table products_02 as
select * 
from products;
UPDATE products_02 
SET base_msrp = base_msrp * 1.05 
WHERE product_type = 'automobile';
DELETE FROM products_02 
WHERE year < 2013; 
-- проверка
select *
from products_02; -- 10 записей (было 12)
```
