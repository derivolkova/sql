## Задание 3.1: найти среднюю цену (base_msrp) только для скутеров ('scooter').

Модернизация запроса: 
1. округление среднего значения до 2 знаков после запятой (путем преобразования типа данных) для читабельности и исключения "ложной точности",
2. условие (base_msrp is not null) исключает факт наличия нулевой стоимости при расчете для точного и достоверного результата.

Скрипт для выволнения запроса:

```
select 
	round(avg(base_msrp)::numeric, 2) as "Средняя стоимость скутеров"
from products 
where product_type = 'scooter' and base_msrp is not null
```

## Задание 3.2: посчитать количество транзакций продаж для каждого dealership_id.

Модернизация запроса: 
1. добавление фильтрации гарантирует выгрузку по крупным диллерским центрам (которые совершили большое количество транзакций) для принятия эффективных бизнес-решений (выгрузка без фильтрации содержит 20 записей, а с ней - 5),
2. добавлено условие (dealership_id is not null), которое равносильно условию channel = 'dealership' (интернет-транзакции не считаются) и это исключает факт ложных данных в выгрузке.

Скрипт для выволнения запроса:

```
select 
	dealership_id,
	count(*) as "Количество транзакций"
from sales
where dealership_id is not null 
group by dealership_id
having count(*) > 2500
order by count(*) desc;
```

## Задание 3.3: Вывести каналы продаж, где максимальная сумма продажи > 15,000.

Модернизация запроса: сортировка по убыванию выводит сначала тот канал, где максимальная сумма продаж больше.

Скрипт для выволнения запроса:

```
select 
	channel, 
	max(sales_amount)
from sales
group by channel
having max(sales_amount) > 15000
order by max(sales_amount) desc;
```
